# 📅 Day 14 - Object-Oriented Programming (OOP)

## 🎯 Objective

Learn the fundamentals of Object-Oriented Programming (OOP) in Python to write modular, reusable, and maintainable programs using classes and objects.

- Method Overriding
- Polymorphism
- Abstraction

- Multilevel Inheritance
- Hierarchical Inheritance
- `super()` Function

## 🧠 Key Takeaways

- Learned how classes act as blueprints for creating objects.
- Understood the purpose of constructors and the `self` keyword.
- Practiced creating reusable classes with attributes and methods.
- Learned the difference between instance variables and class variables.
- Used encapsulation to protect object data.
- Implemented inheritance to reuse existing code.
- Understood method overriding and runtime polymorphism.
- Learned abstraction using Python's `abc` module.
- Built real-world applications using object-oriented design principles.

---

## 💡 Challenges Faced

- Understanding the relationship between classes and objects.
- Distinguishing between instance variables and class variables.
- Choosing the appropriate inheritance type.
- Understanding the use of `super()` in derived classes.
- Implementing abstraction and polymorphism effectively.
