# 📅 Day 17 - Regular Expressions (Regex)

## 🎯 Objective

Learn how to use Python's **Regular Expressions (Regex)** to search, validate, extract, split, and replace text efficiently. Understand how regex simplifies pattern matching for real-world applications like input validation, log parsing, and data extraction.

---

## 📚 Concepts Learned

- Introduction to Regular Expressions
- The `re` Module
- `re.match()`
- `re.search()`
- `re.findall()`
- `re.finditer()`
- `re.split()`
- `re.sub()`
- `re.compile()`
- Character Classes
- Quantifiers
- Anchors (`^` and `$`)
- Capturing Groups
- Named Groups
- Greedy vs Non-Greedy Matching
- Regex Flags
  - `re.IGNORECASE`
  - `re.MULTILINE`
  - `re.DOTALL`

## 🧠 Key Takeaways

- Learned how regex simplifies complex string matching.
- Understood the difference between `match()`, `search()`, `findall()`, and `finditer()`.
- Used regex for searching, splitting, and replacing text.
- Validated common user inputs such as email addresses, phone numbers, passwords, dates, and URLs.
- Extracted structured information from unstructured text.
- Built practical regex-based applications.
