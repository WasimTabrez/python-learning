# 📅 Day 15 - Iterators & Generators

## 🎯 Objective

Learn how Python iterators and generators work to efficiently process data one item at a time, improve memory efficiency, and write clean, reusable code.

---

## 📚 Concepts Learned

- Iterable vs Iterator
- `iter()`
- `next()`
- `StopIteration`
- Custom Iterators
- Generator Functions
- `yield`
- Multiple `yield` Statements
- Generator Expressions
- Infinite Generators
- Lazy Evaluation
- Generator vs List
- File Iteration using Generators
- Memory Efficiency

## 🧠 Key Takeaways

- Learned the difference between iterables and iterators.
- Used `iter()` and `next()` to manually iterate through collections.
- Understood how the `StopIteration` exception works.
- Created custom iterator classes.
- Learned to build generator functions using `yield`.
- Compared generators with lists for memory-efficient programming.
- Used generator expressions for concise and efficient code.
- Built reusable generators for common sequences and data processing.

## 💡 Challenges Faced

- Understanding the difference between iterables and iterators.
- Learning how `yield` pauses and resumes function execution.
- Implementing custom iterator classes correctly.
- Choosing when to use generators instead of lists.
