# 📅 Day 13 - File Handling

## 🎯 Objective

Learn how to create, read, write, append, and manage files in Python using built-in file handling functions and context managers.

---

## 📚 Concepts Learned

- Introduction to File Handling
- Opening Files
- File Modes (`r`, `w`, `a`, `x`)
- Reading Files
- Writing Files
- Appending Data
- `read()`
- `readline()`
- `readlines()`
- `write()`
- `writelines()`
- File Pointer (`seek()` and `tell()`)
- Closing Files
- `with` Statement
- Working with CSV Files
- Working with JSON Files
- File and Directory Operations using `os`
