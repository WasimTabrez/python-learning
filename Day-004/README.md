# 📅 Day 4 - Loops

## 🎯 Objective

Learn how to repeat tasks efficiently using Python loops and solve practical problems using iteration.

---

## 📚 Concepts Learned

- `for` loop
- `while` loop
- `range()`
- `break`
- `continue`
- Nested loops
- Fibonacci sequence
- Pattern printing

---

## 💻 Programs Implemented

| File | Description |
|------|-------------|
| `attendance.py` | Collect present/absent status for N students and print an attendance report |
| `even.py` | Print all even numbers from 1 to 100 |
| `fibonacci.py` | Print the starting 20 Fibonacci numbers |
| `guess.py` | Number guessing game |
| `sum.py` | Sum of the first **N** numbers |
| `table.py` | Multiplication table |

---

## 🧠 Key Takeaways

- Understood the difference between `for` and `while` loops.
- Learned when to use `break` and `continue`.
- Practiced nested loops and pattern generation.
- Implemented the Fibonacci sequence using iteration.
- Improved logical thinking by solving practice problems.

---

## 💡 Challenges Faced

- Understanding how multiple assignment works in the Fibonacci program.
- Learning the difference between modifying and reassigning variables.
- Predicting loop execution without running the program.
