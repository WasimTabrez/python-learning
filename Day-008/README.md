# 📅 Day 8 - Dictionaries

## 🎯 Objective

Learn how to store, retrieve, update, and manipulate data efficiently using Python dictionaries.

---

## 📚 Concepts Learned

- Dictionary Basics
- Creating Dictionaries
- Keys and Values
- Accessing Dictionary Elements
- Adding New Key-Value Pairs
- Updating Existing Values
- Removing Items
- Dictionary Methods
  - `get()`
  - `keys()`
  - `values()`
  - `items()`
  - `update()`
  - `pop()`
  - `popitem()`
  - `clear()`
  - `copy()`
  - `setdefault()`
- Traversing Dictionaries
- Membership Operators (`in`, `not in`)
- Nested Dictionaries
- Dictionary Copying
- Dictionary Comprehension (Introduction)

---

## 💻 Programs Implemented

| File | Description |
|------|-------------|
| `create_dictionary.py` | Create and display a dictionary |
| `access_dictionary.py` | Access dictionary values using keys and `get()` |
| `add_update.py` | Add new entries and update existing values |
| `remove.py` | Remove elements using `pop()`, `del`, and `popitem()` |
| `methods.py` | Demonstrate commonly used dictionary methods |
| `traversal.py` | Traverse a dictionary using loops |

| `copy_dictionary.py` | Demonstrate shallow dictionary copying |

| `frequency.py` | Count character frequency in a string |

| `employee_management.py` | Menu-driven Employee Management System |
| `phone_book.py` | Menu-driven Phone Book Application |


---

## 🧠 Key Takeaways

- Learned how to store data using key-value pairs.
- Practiced adding, updating, searching, and deleting dictionary entries.
- Understood commonly used dictionary methods.
- Learned how to traverse dictionaries using `keys()`, `values()`, and `items()`.
- Worked with nested dictionaries to organize structured data.
- Built a menu-driven Employee Management System using dictionaries.

---

## 💡 Challenges Faced

- Understanding the difference between dictionary keys and values.
- Traversing nested dictionaries.
- Selecting the appropriate dictionary method for different operations.
- Understanding shallow copying using `copy()`.
