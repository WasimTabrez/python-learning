## 🎯 Objective

Learn how to store, access, modify, and manipulate multiple values efficiently using Python lists.

- Creating Lists
- Empty Lists
- List of Different Data Types
- Nested Lists
- Positive Indexing
- Negative Indexing
- List Slicing
- Updating List Elements
- `append()`
- `insert()`
- `extend()`
- `remove()`
- `pop()`
- `del`
- `clear()`
- `sort()`
- `reverse()`
- `copy()`
- List Traversal using `for` and `while`
- `enumerate()`

- Shallow Copy

## 🧠 Key Takeaways

- Learned how to store multiple values in a single variable using lists.
- Practiced accessing elements using positive and negative indexing.
- Understood how list slicing works.
- Learned different ways to add, update, and remove elements.
- Explored commonly used list methods such as `append()`, `insert()`, `extend()`, `remove()`, `pop()`, `sort()`, and `reverse()`.
- Understood the difference between shallow copying and assigning list references.
- Used loops to traverse and process list elements.
- Built a real-world menu-driven **Student Management System** using lists and functions.

- Understanding the difference between `append()` and `extend()`.
- Choosing when to use `remove()` versus `pop()`.
- Remembering list slicing syntax.
- Understanding shallow copy versus list assignment.
- Designing a menu-driven application using functions and lists.
