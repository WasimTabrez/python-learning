## 🎯 Objective

Learn how to create, manipulate, search, format, and process text efficiently using Python strings.

- String Basics
- String Immutability
- Indexing
- Negative Indexing
- String Slicing

- String Concatenation
- String Repetition
- Membership Operators (`in`, `not in`)
- Common String Methods
- String Formatting
- Escape Characters
- Raw Strings
- String Comparison
- Palindrome
- Anagram
- String Reversal

## 🧠 Key Takeaways

- Learned that strings are immutable objects in Python.
- Practiced accessing characters using indexing and slicing.
- Understood commonly used string methods for text manipulation.
- Learned different ways to format strings using f-strings and `format()`.
- Built a menu-driven Student Record Search System using string operations.
- Applied string processing techniques to analyze text.

## 💡 Challenges Faced

- Understanding string immutability.
- Choosing the appropriate string method for different scenarios.
- Handling case-sensitive string comparisons.
- Processing user input with spaces and special characters.
