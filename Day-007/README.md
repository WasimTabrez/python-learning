# 📅 Day 7 - Tuples

## 🎯 Objective

Learn how to create, access, and manipulate tuples, and understand when to use them instead of lists.

---

## 📚 Concepts Learned

- Creating Tuples
- Empty Tuple
- Single-element Tuple
- Tuple Packing
- Tuple Unpacking
- Indexing
- Negative Indexing
- Tuple Slicing
- Traversing Tuples
- `count()`
- `index()`
- Built-in Functions (`len()`, `min()`, `max()`, `sum()`, `sorted()`)
- Nested Tuples
- Tuple Immutability
- Tuple vs List
- Returning Multiple Values from Functions

## 🧠 Key Takeaways

- Learned how tuples differ from lists.
- Understood tuple immutability.
- Practiced tuple packing and unpacking.
- Worked with nested tuples.
- Used tuples to return multiple values from functions.

---

## 💡 Challenges Faced

- Understanding single-element tuple syntax.
- Remembering that tuples are immutable.
- Choosing when to use tuples instead of lists.
