# 📅 Day 9 - Sets

## 🎯 Objective

Learn how to store unique values, remove duplicates, and perform mathematical set operations using Python sets.

---

## 📚 Concepts Learned

- Creating Sets
- Empty Set vs Empty Dictionary
- Set Properties
- add()
- update()
- remove()
- discard()
- pop()
- clear()
- copy()
- Union
- Intersection
- Difference
- Symmetric Difference
- Subset
- Superset
- Disjoint Sets
- Frozen Set
- Set Comprehension (Introduction)

---

## 🧠 Key Takeaways

- Learned that sets automatically store only unique values.
- Practiced adding, updating, and removing elements from sets.
- Understood mathematical set operations such as union, intersection, difference, and symmetric difference.
- Learned the difference between mutable `set` and immutable `frozenset`.
- Built a menu-driven Course Enrollment System using sets.

---

## 💡 Challenges Faced

- Understanding that sets are unordered collections and do not support indexing.
- Choosing the appropriate set operation for different scenarios.
- Understanding the difference between `remove()` and `discard()`.
