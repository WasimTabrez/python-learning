# 📅 Day 16 - Decorators

## 🎯 Objective

Learn how Python decorators work to extend or modify the behavior of functions without changing their source code. Understand first-class functions, closures, and practical applications of decorators.

---

## 📚 Concepts Learned

- Functions as First-Class Objects
- Assigning Functions to Variables
- Passing Functions as Arguments
- Returning Functions from Functions
- Nested Functions
- Closures
- Introduction to Decorators
- `@` Decorator Syntax
- Decorators with `*args` and `**kwargs`
- Multiple Decorators
- Built-in Decorators
- `@property`
- `@staticmethod`
- `@classmethod`
- `functools.wraps()`
- Practical Applications of Decorators

## 🧠 Key Takeaways

- Learned that functions are first-class objects in Python.
- Understood how nested functions and closures work.
- Created reusable decorators to extend function behavior.
- Used `*args` and `**kwargs` to build flexible decorators.
- Applied multiple decorators to a single function.
- Learned the purpose of `functools.wraps()`.
- Explored built-in decorators such as `@property`, `@staticmethod`, and `@classmethod`.
- Built practical applications using decorators.

---

## 💡 Challenges Faced

- Understanding how closures preserve variables.
- Visualizing the flow of decorator execution.
- Working with multiple decorators in the correct order.
- Using `*args` and `**kwargs` effectively inside decorators.
- Preserving original function metadata using `functools.wraps()`.
