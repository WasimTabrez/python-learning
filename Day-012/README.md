# 📅 Day 12 - Exception Handling

## 🎯 Objective

Learn how to handle runtime errors gracefully using Python's exception handling mechanism to build robust, reliable, and user-friendly applications.

---

## 📚 Concepts Learned

- Syntax Errors vs Runtime Errors
- Exceptions
- `try`
- `except`
- `else`
- `finally`
- Multiple Exceptions
- Catching Generic Exceptions
- Raising Exceptions (`raise`)
- Custom Exceptions
- Exception Hierarchy
- Best Practices for Exception Handling
