# 📅 Day 11 - Modules & Packages

## 🎯 Objective

Learn how to organize Python programs using modules and packages, reuse code efficiently, and work with commonly used built-in modules.

---

## 📚 Concepts Learned

- What is a Module?
- Creating Custom Modules
- Importing Modules
- Different Import Styles
- Module Aliasing (`as`)
- Built-in Modules
  - `math`
  - `random`
  - `datetime`
  - `calendar`
  - `os`
  - `sys`
- The `__name__` Variable
- Creating Packages
- `__init__.py`
- Code Reusability
- Introduction to `pip`
