# 📅 Day 5 - Functions

## 🎯 Objective

Learn how to write reusable, organized code using Python functions and apply them to solve practical problems.

---

## 📚 Concepts Learned

- Function definition
- Parameters & Arguments
- Return values
- Keyword arguments
- Iterative loops as an alternative to recursion
- Variable scope

---

## 💻 Programs Implemented

| File | Description |
|------|-------------|
| `greet.py` | Prints a fixed welcome message using a simple no-argument function |
| `calculator.py` | Basic calculator using separate functions for add, subtract, multiply, and divide |
| `employee.py` | Displays employee details using a function with positional parameters |
| `temperature.py` | Converts Celsius to Fahrenheit using a function |
| `area.py` | Calculates the area of a rectangle using a function |
| `factorial.py` | Calculates factorial of a number using an iterative loop |
| `prime.py` | Checks whether a number is prime |
| `shopping_bill.py` | Calculates the total bill for a single item (price × quantity) using a function |
| `add.py` | Adds two numbers |
| `maximum.py` | Finds the maximum of three numbers using manual comparisons (no `max()`) |
| `even_odd.py` | Checks whether a number is even or odd |
| `simple_interest.py` | Calculates simple interest |
| `bonus.py` | Calculates employee bonus based on performance rating |
| `reverse_string.py` | Reverses a string using a manual loop (no slicing) |
| `count_vowels.py` | Counts vowels in a string (case-insensitive) |
| `largest_number.py` | Finds the largest element in a list using a manual loop (no `max()`) |
| `electricity_bill.py` | Calculates electricity bill based on tiered unit rates |

---

## 🧠 Key Takeaways

- Understood how to break problems into reusable functions.
- Practiced passing positional and keyword-style values into functions.
- Rewrote factorial, largest-number, and reverse-string logic as iterative loops instead of relying on built-ins.
- Improved code organization by separating logic into functions.

---

## 💡 Challenges Faced

- Deciding when to replace a built-in (`max()`, slicing) with a manual loop for practice.
- Structuring multi-function programs cleanly.

## 📖 Learning Summary

Today I learned how to write and use functions in Python, including the difference between parameters and arguments, how `return` differs from `print()`, and how local and global variables behave in different scopes. I applied functions to real-world problems such as a calculator, salary display, temperature converter, area calculator, factorial, prime check, and a shopping bill calculator. I also wrote smaller single-purpose functions (add, max of three, even/odd, simple interest, bonus, reverse string, vowel count, largest number, electricity bill), and rewrote `maximum.py`, `largest_number.py`, and `reverse_string.py` to use manual loops instead of the built-in `max()` and slice notation `[::-1]`, which helped me understand what those built-ins are doing internally.
