## 📖 Learning Summary

Today I learned how Python stores data in memory and how variables reference objects. Using `string_test.py`, `person.py`, and `reference.py`, I observed how immutable strings get a new `id()` after modification while mutable lists keep the same `id()` and are shared across variables, which deepened my understanding of assignment versus copying.
