# 📅 Day 3 - Operators

## 🎯 Objective

Learn how to use Python operators to perform arithmetic calculations, compare values, evaluate logical conditions, and solve real-world programming problems.

---

## 📚 Concepts Learned

- Arithmetic Operators
- Comparison Operators
- Logical Operators
- Assignment Operators
- Identity Operators (`is`, `is not`)
- Equality Operator (`==`)
- Membership Operators (`in`, `not in`)
- Operator Precedence

---

## 💻 Programs Implemented

| File | Description |
|------|-------------|
| `atm.py` | Simulate ATM withdrawal and update account balance |
| `bmi.py` | Calculate BMI from user input and categorize the result (Underweight/Normal/Overweight/Obese) |
| `bonus.py` | Calculate employee bonus based on performance rating and compute final salary |
| `student_grade.py` | Calculate total, average, and grade for a student based on marks from five subjects |
| `tax.py` | Calculate annual income tax based on salary |

---

## 🧠 Key Takeaways

- Learned different categories of Python operators and their use cases.
- Understood the difference between equality (`==`) and identity (`is`).
- Applied operators to solve real-world problems such as BMI, tax, bonus, and grading systems.
- Improved understanding of operator precedence and expression evaluation.

---

## 💡 Challenges Faced

- Understanding the difference between identity (`is`) and equality (`==`).
- Remembering operator precedence in complex expressions.
- Selecting the appropriate operators while implementing real-world logic.
